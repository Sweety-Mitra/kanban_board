# 🧩 Kanban Task Board

## 📌 Description

This project is a Kanban-style task management application built using React and TypeScript. It allows users to create, update, and manage tasks across multiple status columns with drag-and-drop functionality. The application also supports infinite scrolling and data persistence.

---

## 🚀 Features

* Create new tasks with title and description
* Edit existing tasks
* Organize tasks into columns:

  * Todo
  * In Progress
  * Completed
* Drag and drop tasks between columns
* Automatic status update on drag-and-drop
* Infinite scroll to load tasks dynamically
* Data persistence using localStorage

---

## 🛠️ Tech Stack

* React (Vite)
* TypeScript
* CSS (can be extended to Tailwind or Material UI)
* dnd-kit (for drag and drop)
* localStorage (for persistence)

---

## ⚙️ Installation & Setup

```bash
git clone https://github.com/Sweety-Mitra/kanban_board.git
cd kanban_board
npm install
npm run dev
```
